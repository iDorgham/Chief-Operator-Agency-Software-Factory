# Code and Repository Rules

- Inspect repository instructions, status, package manager, versions and existing conventions first.
- Preserve user changes; never reset or force-push.
- One implementer owns overlapping scope.
- Make the smallest coherent change; do not migrate frameworks to match a tutorial.
- Validate untrusted input and authorize on the server.
- Run actual repository scripts and report failures honestly.
- Commit, push, open/merge PR or deploy only when explicitly requested.
