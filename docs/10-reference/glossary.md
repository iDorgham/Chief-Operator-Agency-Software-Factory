# Glossary

- **Agent:** persistent role with durable instructions and workspace/context.
- **Subagent:** temporary bounded worker accountable to a parent lead.
- **Skill:** reusable task-specific instructions loaded when relevant.
- **Factory Core:** authoritative operational state and transition engine.
- **Control Desk:** human interface over Factory Core.
- **Artifact:** versioned work product with owner and evidence.
- **Approval:** explicit decision for an exact action and version.
- **Capability:** verified tool/provider/model function with constraints and last check.
- **Memory:** curated scoped knowledge with provenance and review policy.
