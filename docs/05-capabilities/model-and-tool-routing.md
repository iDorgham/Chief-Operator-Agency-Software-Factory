# Model and Tool Routing

Maintain a dated capability registry from live selectors. Choose by quality, risk, latency, cost, privacy and commercial rights.

- Highest reasoning: Chief Operator, consequential architecture and cross-system debugging.
- Balanced: normal coding, planning, marketing strategy and professional writing.
- Visual/computer: UI inspection and computer interaction.
- Economical: bounded extraction, formatting, classification and routine summaries.
- Specialized media: image/video generation under approved rights and provenance policy.

Codex is the primary factory architect and code implementer. OpenBot is the persistent organization and business-workflow surface after verification. T3 Code is the coding-agent control plane for Codex, Claude Code, OpenCode and other supported coding agents; it is not a model and is distinct from the T3 web stack. Claude is a selective alternate or independent reviewer. OpenCode, Qoder and Kilo are bounded fallback lanes. Copilot is primarily inline assistance. Never run competing implementers on the same scope.
