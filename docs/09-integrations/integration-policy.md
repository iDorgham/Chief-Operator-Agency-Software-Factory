# Integration Policy

Connect services only for an approved workflow with a named owner, minimum scopes, data classification, cost boundary, failure behavior and revocation path. Verify one harmless read before any write. Verify one bounded test write before live use. Record receipts and last-verified time.

Priority order: OpenBot team setup, T3 Code local coding control plane, test GitHub repository, design workspace, media providers, analytics/search, publishing and advertising. Each remains independently disabled until its acceptance test passes.

See [OpenBot and T3 Code](openbot-and-t3-code.md).
