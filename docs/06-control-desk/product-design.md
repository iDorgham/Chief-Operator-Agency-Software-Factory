# Control Desk Product Design

The Control Desk is the operator's interface over Factory Core. It must show projects, active work, team ownership, phase timelines, evidence, blockers, approvals, audit events, capability status and improvement proposals.

Primary views: Home, Projects, Work Queue, Active Run, Approvals, Team, Capabilities, Evidence, Audit, Improvements and Settings. Demo and Live state must be unmistakable. The interface never implies an external action succeeded without a receipt.

See [Dashboard Plan](../../plans/dashboard/control-desk-plan.md).
