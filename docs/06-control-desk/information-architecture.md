# Control Desk Information Architecture

Desktop uses a compact navigation rail, project context header and task-focused workspace. Mobile prioritizes active work, approvals and blockers. Status uses text and icons in addition to color. Every approval card exposes exact action, target, version, evidence and consequences.

Core objects remain consistent across screens: Project, Task, Run, Artifact, Approval, Agent, Capability and Event.
