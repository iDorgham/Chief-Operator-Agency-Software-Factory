# System Overview

The factory is one human-controlled organization, not a crowd of unrelated chatbots. The operator gives objectives to the Chief Operator. The Chief Operator maintains project identity, delegates bounded work to professional leads, reconciles evidence and returns one coherent response.

The organization covers software, product, design, marketing, text/image/video production, analytics and operations. Coverage is provided by the Chief Operator and seven persistent leads plus on-demand skills and temporary subagents. Persistent roles are not created for occasional specialties.

## System layers

1. **Governance:** authority, approvals, safety and quality gates.
2. **Organization:** Chief Operator, team leads and specialist subagents.
3. **Factory contracts:** versioned briefs, specifications, handoffs, results, reviews, approvals, events and memory.
4. **Factory Core:** future authoritative operational state.
5. **Control Desk:** future human interface over Factory Core.
6. **Adapters:** OpenBot, GitHub, coding tools, design/media, analytics and publishing services.

Phase 1 is file-based and useful without external integrations. See [Operating Model](operating-model.md) and [Architecture](../02-architecture/system-architecture.md).
