# Operating Model

## Daily loop

1. Operator states an objective, constraints and desired outcome.
2. Chief Operator selects or creates project context and identifies material unknowns.
3. Product Lead establishes an approved brief/specification.
4. Delivery Manager creates bounded work and ownership.
5. Leads execute or delegate through structured handoffs.
6. An independent lead reviews evidence when risk requires separation.
7. Chief Operator consolidates results, disagreements, risks and approvals.
8. Operator decides consequential actions.
9. Operations Lead records outcomes and improvement proposals.

## Completion truth

- Written instructions are not proof of configuration.
- Generated code is not proof of a working application.
- A provider name is not proof of account access or commercial permission.
- Missing evidence is never treated as success.
