# Marketing and Growth Workflow

Objective -> evidence-backed audience/offer -> strategy -> channel plan -> calendar -> creative production -> claim/brand review -> approval -> optional publish/spend -> measurement -> retrospective.

SEO, AEO, GEO, social, advertising and analytics outputs distinguish observed data, sourced research, estimates and recommendations. Unavailable data is never fabricated.
