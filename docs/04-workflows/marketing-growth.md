# Marketing and Growth Workflow

Objective -> evidence-backed audience/offer -> strategy -> channel architecture -> social/editorial plan -> calendar -> creative production -> claim/brand review -> approval -> optional scheduling/publishing/spend -> community management -> measurement -> retrospective.

SEO, AEO, GEO, social, advertising and analytics outputs distinguish observed data, sourced research, estimates and recommendations. Unavailable data is never fabricated.

Social media is operated as a managed system rather than a stream of isolated posts. It includes platform purpose, audience segment, content pillars, formats, cadence, production ownership, review queue, response policy, escalation, automation boundaries, metrics and improvement. See [Social Media Operating System](social-media-system.md).
