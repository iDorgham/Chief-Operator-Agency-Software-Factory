# Creative Production Workflow

Approved brand/creative brief -> research/source inventory -> UX/content direction -> copy/image/video plan -> draft -> accessibility/rights/claims review -> operator approval -> export/publish only when authorized.

Text, image and video deliverables record brief version, channel/format, sources, claims, asset rights, generation model/tool where applicable, reviewer and approval status.
