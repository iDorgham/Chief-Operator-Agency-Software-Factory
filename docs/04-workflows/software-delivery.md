# Software Delivery Workflow

Request -> approved brief -> specification -> architecture/design -> bounded tickets -> repository preflight -> one implementer -> tests -> independent evidence review -> current-head CI -> approval -> merge/deploy when authorized -> retrospective.

Support web, dashboard, API, desktop and mobile projects through stack-specific skills. Reconcile branches, pull requests and external writes before retrying. Missing or stale checks block release.
