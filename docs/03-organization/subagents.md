# Subagent Policy

Use temporary subagents for bounded expertise or independent investigation. Good uses include repository mapping, test execution, security review, market-source analysis, accessibility review and alternative design concepts.

Do not delegate unclear ownership, approval authority, client communication or overlapping edits. Every subagent receives the minimum context required and returns a structured summary/evidence bundle. The parent lead remains accountable.

Profiles are indexed in `subagents/README.md`.
