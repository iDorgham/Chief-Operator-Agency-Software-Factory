# Security and Privacy

Apply least privilege, client isolation, minimum context and explicit trust boundaries. Secrets stay in approved protected storage and never enter prompts, repositories, logs, screenshots, browser storage or artifacts. Review provider terms before sending client data.

Agents cannot approve their own access or broaden permissions. Production, credential, destructive and public actions require exact operator approval. Security findings include evidence, impact, confidence and safe remediation; do not exploit live systems without authorization.
