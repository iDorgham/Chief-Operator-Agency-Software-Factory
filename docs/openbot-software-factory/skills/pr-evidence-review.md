# Skill: PR Evidence Review

## When to use
Use for the named repeatable workflow.

## Owner agents
QA Reviewer, Product Architect (two-invoker test passed).

## Inputs
Approved source artifacts only.

## Numbered deterministic steps
1. Confirm PR and spec version. 2. Map every criterion to diff/test evidence. 3. Mark pass/fail/not evidenced. 4. Check out-of-scope changes. 5. Write approve/reject with reasons.

## Output format
Review template; missing evidence is not pass.

## Tier
Tier 0/1; estimate 1–3k input tokens, not a billing guarantee.

## Example
A synthetic task follows the steps and returns the specified artifact.
