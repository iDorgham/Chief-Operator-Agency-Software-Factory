# Skill: Content Production

## When to use
Use for the named repeatable workflow.

## Owner agents
Content Producer, Client Partner (two-invoker test passed).

## Inputs
Approved source artifacts only.

## Numbered deterministic steps
1. Confirm approved brief/calendar. 2. Check channel/audience/objective. 3. Draft only from supplied facts. 4. Flag claims to verify. 5. Check voice/accessibility/CTA. 6. Return for human approval.

## Output format
Draft mapped to calendar item; no publishing.

## Tier
Tier 0/1; estimate 1–3k input tokens, not a billing guarantee.

## Example
A synthetic task follows the steps and returns the specified artifact.
