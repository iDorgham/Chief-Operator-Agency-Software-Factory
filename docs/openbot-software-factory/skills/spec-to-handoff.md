# Skill: Spec-to-Handoff

## When to use
Use for the named repeatable workflow.

## Owner agents
Product Architect, Delivery Planner (two-invoker test passed).

## Inputs
Approved source artifacts only.

## Numbered deterministic steps
1. Confirm approved spec/version and client IDs. 2. Extract testable criteria. 3. Split bounded tickets. 4. Set permitted scope, tests and do-not-touch list. 5. Block if criteria are absent. 6. Fill handoff template.

## Output format
Tickets plus handoff schema-compatible fields.

## Tier
Tier 0/1; estimate 1–3k input tokens, not a billing guarantee.

## Example
A synthetic task follows the steps and returns the specified artifact.
