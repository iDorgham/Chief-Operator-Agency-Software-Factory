# Token Economy
T0 routine; T1 synthesis; T2 consequential ambiguity/high-stakes/final QA. Context pack: spec + repo + criteria + do-not-touch only. Approx inputs: prompt <1k, skill 1–3k, spec 3–8k, review 3–10k. Not provider pricing/limits. Top sinks: repeated history (link files), huge diffs (narrow), premium retries (fix criteria). Weekly audit tiers/retries/idle roles. Warning signs: routine T2; repeated paste; duplicate edits; vague retries; unused agents. Escalation note: uncertainty, consequence, evidence, decision, why lower tier failed.
