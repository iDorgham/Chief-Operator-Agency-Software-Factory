# Dots Layer
Use portable single-purpose prompts from `../prompts/` for mobile reply, spec check, PR description and voice/claim checks. Existing custom GPTs may be used if the account permits, but do not make the system depend on creating new GPTs: current OpenAI documentation says creation is unavailable on personal accounts and a migration/retirement transition is underway. Keep versioned prompt files in the repo as the durable source. Draft/check only; never treat a GPT as canonical memory, sender or publisher. Refresh from the source file and test with synthetic material. See [OpenAI GPT policy](https://help.openai.com/en/articles/8554397-creating-a-gpt).
