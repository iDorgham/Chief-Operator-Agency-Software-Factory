# Agency Pipeline
Lead (Intake) → brand brief/identity (Brand + operator) → build (Architect/T3/QA) → strategy/calendar (Strategist) → drafts (Producer) → human-approved publishing → monthly report (Client Partner). Store work in `work/clients/<id>/projects/<id>/`; never copy system source into client folders.
