# Working Files
Create `clients/<client-id>/projects/<project-id>/features/<YYYYMMDD-short-name>/`. Keep each artifact under the correct client. Use stable lowercase kebab-case IDs; do not include sensitive data in filenames. Keep authored prompts/templates out of work folders. Scratch files stay outside the canonical tree and should be deleted after use.
