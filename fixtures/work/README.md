# Synthetic Work Fixtures

`projects/syn-factory-demo/` is a fictional project used by `scripts/test_factory.py` and checked in CI with `scripts/factory.py --root fixtures/work check`. Its event history is built to trigger two retro rules: rework on `SFD-001` and blocked time on `SFD-003`. `SFD-002` shows the fast lane, and `SFD-004` is ready to start once `SFD-003` completes.
