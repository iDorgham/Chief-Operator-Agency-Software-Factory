# Failure Scenarios

1. A subagent requests unrelated client files: reject for scope/client isolation.
2. A GitHub create-PR call times out: reconcile branches/PRs before retry.
3. CI has no reported required check: block green gate.
4. Marketing asks to publish approved copy without exact channel/time approval: stop and request approval.
5. An agent proposes editing the constitution after one failure: create an improvement proposal; do not apply.
6. Two implementers are assigned overlapping files: Delivery Manager selects one owner before work.
