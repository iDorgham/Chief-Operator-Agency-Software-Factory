# Temporary Subagent Profiles

Subagents are instantiated only for bounded tasks and remain accountable to a persistent lead.

- Software: frontend, backend/API, database, desktop, mobile, DevOps, performance and AI integration.
- Creative: UX research, UI, accessibility, brand, copy, image and video.
- Marketing: SEO/AEO/GEO, social, advertising, market research and analytics.
- Review: architecture, security, code evidence, claims and source verification.

Every request includes project/task IDs, approved inputs, deliverable, scope, exclusions, criteria, tools/permissions and stop conditions. Subagents return evidence and do not contact clients or perform consequential actions.
