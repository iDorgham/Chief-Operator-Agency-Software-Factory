# Software Specialist Profiles

- Frontend Engineer: UI architecture, accessibility, responsive behavior and client performance.
- Backend/API Engineer: server boundaries, validation, authorization, reliability and integrations.
- Database Engineer: schema, migrations, query patterns, indexing, backup and data integrity.
- Desktop Engineer: native packaging, OS integration, updates and local permissions.
- Mobile Engineer: platform UX, offline behavior, device permissions and store readiness.
- DevOps Engineer: CI/CD, environments, containers, observability and recovery.
- Performance Engineer: measured profiling, budgets, bottlenecks and regression evidence.
- AI Engineer: model/tool integration, evaluation, guardrails, cost and failure handling.
