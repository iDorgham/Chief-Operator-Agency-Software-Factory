# Phase 2 — OpenBot Configuration

## Preconditions

Verify installed version, commercial-use license, signed-in providers, server ownership, permissions, data policy and Marketplace behavior.

## Steps

1. Import Chief Operator only; verify private bounded task.
2. Import leads one at a time and test their output contracts.
3. Create team channels only where multi-role conversation adds value.
4. Install minimum required skills; keep consequential routines inactive.
5. Run synthetic software and marketing handoffs.
6. Record observed capability status and discrepancies.

No Marketplace submission, public sharing, external messages or live routines are authorized by this plan.
