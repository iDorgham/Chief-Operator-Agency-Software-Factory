# Factory Design Plan

Design language: calm professional operator console; warm neutral canvas, ink/navy text, restrained cobalt active state, emerald success, amber waiting and red blocked. Status never relies on color alone.

Deliver future wireframes for mobile and desktop Home, Project, Active Run, Approval, Team, Capability and Audit views. Use a small token system, accessible typography, keyboard navigation, visible focus, responsive tables/cards and reduced-motion behavior.

Creative team assets use approved brand brief and keep source/rights/provenance. No decorative media is required for the internal console.
