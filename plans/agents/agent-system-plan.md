# Agent System Plan

The Chief Operator and seven persistent leads own recurring artifacts. Temporary specialists receive bounded delegation contracts and return structured results. Chief Operator maintains the shared project view and consolidated operator response.

Each agent definition contains identity, mandate, owned artifacts, inputs, outputs, skills, memory scope, boundaries, escalation, model tier and result contract. No role embeds credentials or provider-specific secrets.

Promotion rule: create another persistent role only after repeated usage, distinct durable context and clear non-overlapping artifact ownership are demonstrated.
