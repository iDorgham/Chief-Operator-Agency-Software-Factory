# Model Capability Routing

Inspect live selectors/status. Record tool, provider, displayed model, capabilities, constraints, commercial rights, data-policy reference and verification time. Choose the lightest verified option meeting quality. Use one primary implementer and selective independent review. Do not buy plans or change account policy.
