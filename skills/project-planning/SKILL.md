# Project Planning

Confirm approved source/version. Define milestones and a vertical first slice. Create stable task IDs, one owner, dependencies, criteria, exclusions, evidence and return path. Keep parallel tasks non-overlapping and blockers explicit. Update the task register; do not start implementation.
