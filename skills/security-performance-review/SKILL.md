# Security and Performance Review

Map trust boundaries, data, identities, inputs and critical operations. Review authorization, validation, secrets, dependencies, logging and failure behavior. Measure before optimizing; check accessibility. Report evidence, impact, confidence and safe remediation. Do not exploit live systems or broaden access.
