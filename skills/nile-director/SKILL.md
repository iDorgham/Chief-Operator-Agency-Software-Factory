## Rules

- Start a new project from the **Master Execution Prompt** in Module 11.9.
- Never invent prices, dates, offers, claims, permits or testimonials; mark them `CLIENT TO CONFIRM`.
- Never render text, logos or UI inside generated media; typeset Arabic RTL in post.
- Every asset passes the 10-point Production-Grade Test, including the Magnific finishing pass.
- Higgsfield and Magnific features change: verify current feature set before production.
- Do not publish, spend or send anything without explicit approval of the exact action.
- All brands and people in the examples are fictional.
