# UX/UI Design

Confirm users, jobs, environment, brand and accessibility. Map primary/exception flows and hierarchy. Define justified tokens/primitives. Specify desktop/mobile and loading, empty, error, blocked, success and approval states. Use semantic structure, keyboard/focus, contrast and reduced motion.
