# OpenBot Verification Checklist

- [ ] Installed version and server/client context recorded.
- [ ] Commercial license permits intended agency/client use.
- [ ] Provider/model selectors tested with harmless prompts.
- [ ] Workspace and permission modes understood.
- [ ] Chief Operator imported and bounded task passed.
- [ ] Each lead imported individually and boundary tested.
- [ ] Private handoff returns structured result.
- [ ] Channels contain only necessary members.
- [ ] No consequential routine active.
- [ ] No credentials or private client material in role instructions.
